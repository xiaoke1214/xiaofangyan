# 乡语智库 - 方言语音数据工厂 Web 管理端
> 方言语音采集、语料审核、任务管理数据平台前端（Vite + Vanilla JS）

## ✅ 当前进度
- 基础工程：Vite 初始化，路由、页面框架搭建完成
- 核心模块：
  - 数据看板：区域联动统计（省→市→区县级联下拉）
  - 方言内容 & 任务管理：管理员创建、配置采集任务
  - 语料审核管理：管理员全局监控审核队列（独立审核员工作台已移除）
  - 激励结算、提现管理模块
  - 数据资产/数据集管理、模型系统管理
  - 用户、角色权限管理（前端暂不开放新建角色按钮）
- 权限逻辑：共用登录接口，后端通过角色 `admin` 判断权限，无权限返回 403
- 模拟数据：内置张家口全套区县 mock 数据，支持按区域筛选统计
- 页面形态：SPA 单页应用，角色化菜单，状态色标体系

## 📌 前后端分工（当前约定）
- 前端：页面渲染、表单、区域联选、状态展示、参数拼装、token 携带
- 后端：接口实现、权限校验、数据统计、积分/奖励规则存储、结算逻辑
- 登录接口：`POST /api/v1/auth/login`，token 放在 `Authorization: Bearer <access_token>`

## 📦 技术栈
- 构建工具：Vite
- 语言：原生 JavaScript + CSS
- 对接：后端 RESTful API
- 版本管理：Git + GitHub
